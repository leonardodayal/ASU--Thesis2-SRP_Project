# Email Inbox

Export new project email threads as `.eml` or PDF and place them in this folder. Keep attachments with the exported thread when possible.

After adding files, ask Codex to process the email inbox. The processing step should:

1. identify new facts, measurements, decisions, and requested actions;
2. distinguish confirmed values from assumptions and unresolved questions;
3. update `SupportingDocuments/EVIDENCE_SUMMARY.md` and the project handoff files;
4. rename and move the source into the appropriate retained-evidence location; and
5. report any referenced attachments that are still missing.
